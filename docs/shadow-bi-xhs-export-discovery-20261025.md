本轮只探索和下载样本，未接正式数仓、未改变投放、未新增调度。腾讯、巨量按用户要求暂不处理。样本及页面证据位于`.local/audits/xhs-export-discovery-20261025/`，无登录凭据。

## 已实测的入口

星火 `https://mcc.xiaohongshu.com` → 聚光营销分析 → 对应代理商子账户“进入聚光” → 数据。

- 完整费用入口：账户 → 账户报表 → 分日 → 明确日期 → 数据明细下载。当前样本CSV为“时间、消费、展现量、点击量、私信进线/开口/留资”等，与既有三份语培费用输入的账户日报方向一致。
- 素材流水入口：标准投 → 笔记报表 → 分日 → 明确日期 → 数据明细下载。导出含时间、笔记ID、笔记跳转链接、消费、效果指标及笔记素材类型。
- 星火财务“流水查询”不是本轮寻找的素材效果流水，不能直接替代广告消耗。

## 自动采集可行方向

实际账户日报导出请求为提交长任务→轮询状态→取得结果→下载CSV。已观察`POST /api/light/long_task/submit`（顶层键task_name/input/source/module_name）、`GET /api/leona/longTask/download/task/status`及`GET /api/leona/longTask/download/task/result`。这是现有登录浏览器下成功导出，尚未证明脱离浏览器的脚本重放或云端跨日免登录。

采集应同时保存账户日报和素材日报，标识品牌账户、代理商子账户/投放ID及日期。两类报表是同笔费用的不同粒度，不能相加。每个报表会记住自己的上次日期，不能只切换账户而沿用日期。星火当前组织有5个品牌主账户、20个子账户，包含旧代理商停用账户；历史期间可能需涵盖它们，不能只采当前在投账户，也不能将主、子账户重复求和。
