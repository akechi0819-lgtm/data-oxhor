# 用户指南

经营分析先明确期间、部门、范围与指标。新媒体周报再核对投放及素材覆盖日期。已确认业务事实用同一批数据核对，文件交付保留受控查询证据。

- 日更或故障恢复使用[日更运维技能](../.agents/skills/daily-ops/SKILL.md)。
- 查经营结果、验证范围和归因使用[经营分析技能](../.agents/skills/biz-analysis/SKILL.md)。
- 周报、项目套图和双周报使用[双周报技能](../.agents/skills/biweekly-report/SKILL.md)。

项目入口维护工作区、来源身份及交付路径，见[根入口](../AGENTS.md)。
