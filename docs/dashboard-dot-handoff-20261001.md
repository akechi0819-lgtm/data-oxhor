## 可复用入口

源码运行，不要求先物理合并主/影子仓，也不引入BI服务。

```bash
python3 -m dashboard_product.management.build \
  --workspace <客户工作区> --snapshot-id <显式current_snapshot_id> \
  --run-id <唯一运行编号> --as-of-date <日期>
python3 -m monitoring_product.shared_preview \
  --shared-result <本批次输出>/shared_result.json \
  --output-dir <本批次输出>/notify_preview \
  --dashboard-base-url <已确认的看板地址>
```

核心文件：

- `dashboard_product/management/build.py`：一次批次取数、共同计算与静态产物。
- `aggregate.py / facts.py / notifications.py / online_view.py`：规则、事实、播报数据及线上投影。
- `monitoring_product/shared_preview.py`：只读共同结果并生成HTML/PNG/XLSX/Markdown，校验通知引用哈希及同批身份。
- `workspace_modeling/operations/people.json`：语培/虚拟人人员和目标；`dashboard_product/config/offline_market_people.json`：留学个人名单和明确线下工单。
- `dashboard_product/config/confirmed_cash_team_overrides.json`：本轮明确现金归属确认。

`site/`只含可展示数据；`details.json`、`notifications.json`、查询回执是私有核对资料，不整体公开。PNG/XLSX是指定交付物，日后发布仍按既有访问边界处理。若dot使用安装包而非源码目录，届时须验证SQL、模板和配置文件的资源打包，不能只安装Python文件。
