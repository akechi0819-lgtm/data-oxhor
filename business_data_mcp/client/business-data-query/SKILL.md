name: business-data-query
description: 主管询问本公司的渠道或学校贡献变化、下降原因，或语培与留学工单、现金、签约和小语种实缴时，用已配置的 Business Data MCP 按需取数、回答追问或交付完整 CSV。
---

先调用 `describe_business_context` 并按问题用 `read_business_context` 读取相关已确认 Bridge、看板口径和官方记分卡；官方记分卡仅在所列指标与期间覆盖范围内优先。需要看板正式结果时使用 `read_dashboard_data`；五张明细表不包含所有看板依赖，不得凭缺失的费用或人员等数据声称完整复算。

根据问题调用 `describe_data`，按需查看域、表和字段。SQL 使用返回的完整 `relation` 和 DuckDB 方言，通过 `query_data` 提交只读查询并传入 `expected_release`。只取本题需要的数据。追问沿用相同版本；版本不可用时说明变化，按新版本重新核对相关数字。

按业务问题选择渠道字段、日期事件和比较范围，并说明所用口径。先检查日期原值：Excel 日期序号含时间小数时，用 `DATE '1899-12-30' + CAST(FLOOR(TRY_CAST(列 AS DOUBLE)) AS INTEGER)` 取日期；日期字符串按实际格式解析。使用可读日期边界核对查询范围。

语培工单先按 ID 和来源行号取得唯一工单，再按工单 ID 左连现金事件；一对多关联后按各自粒度计数，现金收入、报入现金收入分别核算。留学签约按合同编号核对唯一性后取签约金额，小语种取来源行实缴金额。未匹配记录保留在所问范围内。官方指标按服务提供的已确认口径和记分卡适用范围处理。

分析结论应有数据或业务信息作为论据，分清查实事实与原因假设，说明关键不确定性。调查路径、追问和呈现方式由宿主模型根据问题决定；证据不足时交代还需核实什么。

小结果直接回答，注明范围、日期口径和数据截至日。更多行通过同一结果 ID 调用 `read_query_result`。需要 CSV 时，用 `export_query_csv` 从偏移 0 开始，按返回的下一偏移读到末段，原样拼接 CSV 文本，只保留第一段表头；用 CSV 解析器核对数据行数等于 `row_count` 后交付本机文件。保留文本 ID、金额小数位和空值。

主管提供的分类、周期和业务背景按其说明用于本题。主管要求以后复用时，把规则和适用期保存到指定的本机笔记，新会话读取该笔记；注明个人口径，并区分数仓取数、主管口述和本地文件的来源。
