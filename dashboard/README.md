## Contract

- 输入：当前 Snapshot；维护表 `config/team_members.csv`、`config/targets.csv` 与 `config/team_mapping.csv`。
- 指标：工单数量按去重工单 ID 计数；被动现金按现金底稿 `渠道属性 = 被动` 且 `报入现金收入 > 0` 汇总，负向现金不计入。
- 新生报名校区口径：固定 SQL `sql/new_student_signup_by_campus.sql` 使用 `初中/初中国际学科/青少` 与 `新老生类型=新生`；人头为窗口内同一学员编号、班级编码的报入现金净额绝对值 `>=1500` 且报名人次大于零的学员编号去重。报入现金只汇总正向报入现金收入，报名单笔为正向报入现金除以合格去重人头。
- 对齐限制：人头按校区展示时校区行可因跨校区学员相加而大于总计；总计必须跨校区再次按学员编号去重。
- 时间：财年 `Q1=6-8月`、`Q2=9-11月`、`Q3=12-次年2月`、`Q4=3-5月`；筛选器支持单季度和 `全年累计`。
- 输出：固定 SQL 查询结果 JSON，供本地看板或后续服务器适配层读取。
- 错误：Snapshot 或必需表头/映射缺失时失败并说明原因，不回退到模糊文件或直接连接数据库。

## 固定 SQL

- `sql/actuals_by_quarter.sql`：团队维度的工单数量与被动正向报入现金；供 `refresh.py` 调用。
- `sql/new_student_signup_by_campus.sql`：留学预备新生报名校区明细。使用列名占位符，执行前由刷新层按现金表首行表头解析为当前物理列；不得依赖固定 `column_n` 编号。

本地启动：`python3 dashboard/server.py`，访问 `http://127.0.0.1:8787`。页面的“刷新”按钮调用固定刷新脚本，不要求手工执行命令。

## 分区

1. `config/`：可维护的成员和目标映射。
2. `sql/`：按业务列名占位符编写的固定查询模板，刷新时解析首行表头。
3. `runtime/`：刷新运行产物（按 run_id 分目录，禁止覆盖历史结果），`latest.json`供页面读取。
4. `server.py`：本地 HTTP 服务，提供页面、最新结果和按钮刷新接口。
