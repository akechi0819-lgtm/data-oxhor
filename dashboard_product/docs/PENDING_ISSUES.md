# Dashboard Product - 待处理问题

## 1. 现金数据团队归属分配问题

### 问题描述
当前查询中，有965条现金记录（总金额约1400万元）无法通过工单ID匹配到工单表，因此无法确定它们属于哪个团队（线下市场/线上平台/线上私域）。这些记录目前被标记为"暂无法匹配"。

### 根本原因
- 现金表中的 `工单ID` 字段与工单表的 `ID` 字段无法匹配
- 现金表的 `渠道` 字段值（市场资源、TMK激活-A类、大客服推荐-外呼）无法直接映射到团队分类

### 当前状态
在 SQL 查询文件 `customers/bi_operations/Work/SavedQueries/dashboard_actuals/v6/query.sql` 中：

```sql
), cash_matched AS (
 SELECT DATE_TRUNC('month', c.cash_date)::DATE AS month_start,
 COALESCE(o.team_id, '暂无法匹配') AS team_id,  -- 无法匹配时标记为"暂无法匹配"
 ...
```

### 数据分布（2026财年至今）
- **暂无法匹配**: 965条记录，14,016,031元
  - 市场资源: 639条, 9,602,540元
  - TMK激活-A类: 325条, 4,410,511元
  - 大客服推荐-外呼: 1条, 2,980元

### 解决方案（待实施）
需要补充新的SQL逻辑来将这些现金记录分配到正确的团队：

1. **方案A**: 通过活动名称匹配
   - 活动名称中包含"线上"关键词 → online_platform
   - 活动名称中包含"线下"关键词 → offline_market
   - 活动名称中包含"虚拟人"关键词 → online_private

2. **方案B**: 通过渠道字段映射规则
   - 需要业务方提供渠道字段到团队的映射规则

3. **方案C**: 混合方案
   - 优先级1: 通过工单ID匹配（已实现）
   - 优先级2: 通过渠道字段映射（待补充规则）
   - 优先级3: 通过活动名称关键词匹配（可作为兜底）

### 影响范围
- 团队层级的现金指标统计不准确
- 业务组层级的现金数据可能准确（因为现金表自带团队字段可映射业务组）
- 人员层级的现金归属无法确定
