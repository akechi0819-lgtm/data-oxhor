# 原生 BI 共同业务计算

本模块保留经营计算、归属和人员规则。现行日更从 `data_acquisition.jobs.prepare_full_daily --publish` 进入 SQL 建仓与 P4 发布，Superset 和日报使用同批正式 release。核对本机批次、服务器版本及日程的方法见[部署说明](../DEPLOYMENT.md)。

## 计算入口

现行 SQL 业务计算位于 `dashboard_product/shadow_bi/sql_warehouse/`，来源 SQL 位于本目录 `sql/`。历史记录见[清理与暂停回执](../../docs/archive/server-cleanup-20261026.md)。

## 现行口径

- 语培工单使用已验收团队/业务组范围，并按被动／主动／全部筛选；全部为主动加被动，不把未分类猜入。留学从独立Snapshot读取，不混入语培。
- 语培经营人头：在筛选范围内按学员编号＋班级编码汇总报入现金，金额绝对值达到1500元且报名人次为正，再按学员编号去重。期间、部门各自重算，不相加子组或月份去重数。个人业绩与人员产能沿各自独立资格，不随经营范围切换。
- 个人工单支持删除／回收与死单两个独立状态范围，现金、人头、目标与人员在职资格不随工单开关改变。通知使用确认的固定资格，页面筛选不改通知合同。
- 个人分配使用共享 `activity_co_creation_weights` 与当前花名册；本业务主办与跨业务接收分别按确认规则计算，不把已明确主办成果无差别均分。人员归属、绩效月、共创及跨业务标记以 `workspace_modeling/operations/` 为准。
- 留学资源按分单日期与资源ID；签约与小语种实缴按各自确认日期/金额/本行归属。明确线上或线下团队而无法匹配个人的签约／实缴只计团队；留学线上汇总包含虚拟人，总计排除SSC并保留国际市场，SSC可单列。留学客户与小语种学员分别在各范围内去重。缺覆盖与无同比保持原样。官方记分卡覆盖范围优先，不被数仓或历史对账覆盖，也不自动回写目标。
- 广告费用仅消费用户提供的原表及 `Input/AdvertisingCosts/sources.json` 明确相对路径/hash。ROI与单条工单成本按费用共同覆盖窗口；缺费用为空，不补0、不将月度累计差额分摊到每天。见 [费用说明](../../docs/dashboard-advertising-costs.md)。

## 完整性与证据

历史 raw 链路中，最大记录日不等于上游完整业务日。其门禁验证受保护来源证明，区分最大记录日与经验证昨日；完整零业务日不补造事实。证明贯穿计算、封口、候选复用与发布末次复核，缺失/变化就停止。该门禁上一轮只合入本地，未由此次清理部署服务器。见 [完整性合同](../../docs/server-source-completion-candidate.md)。

共同计算在工作区Output保存受控查询回执、费用/人员/来源诊断及绑定身份；封存业务库保留明确输入、规则与表hash。原始输入只读，不直连客户DuckDB、不从目录时间或latest猜当前状态。历史V14对账仅是方法核对，不覆盖当前事实。

## 验证与维护

规则回归位于 `tests/` 和本目录 `tests/`；全量入口为 `sh tools/run_tests.sh`。原生BI类型库、权限、通知与失败恢复使用各自现有测试；旧静态渲染/打包/发布测试随删除代码一并移除，不保留只检查文件不存在的占位测试。清理清单及结果见 [旧静态退出记录](../../docs/archive/retire-static-dashboard-20261026.md)。
