# Grok Bot 工作区边界

本目录允许按用户任务自由维护角色说明、笔记和辅助程序。内容默认不属于核心产品，不自动提交、发布或回写覆盖上级源码。

- `roles/`、`programs/`、`scratch/`、`notes/`、`history/` 按任务使用；依赖放在具体程序自己的环境中，不污染共享 venv。
- 业务事实仍通过核心 Data Platform 受控只读入口取得，显式指定工作区、Snapshot 和 run；不直接连接客户 DuckDB，不修改原始输入或未确认口径。
- 调用核心 CLI 时使用明确的核心 checkout 作为 cwd 和既有 Python 环境，避免本目录临时程序遮蔽核心同名模块。
- 看板、监控、SQL、人员规则与目标配置属于核心产品；没有对应修改任务时保持只读。自管脚本不能成为例行发布/查询的隐含依赖。
- 本目录角色材料由 Grok 自行维护；核心职责、数据边界与正式接口以项目合同为准。发生冲突时先说明具体问题，不自行给核心增加兼容层或总控。
- 不把密钥、客户数据或整个自管目录放入核心发布包；临时成果只有经过明确选取和验收后才转入对应正式工作区。
