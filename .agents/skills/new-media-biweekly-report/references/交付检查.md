# 双周报核算与交付检查

## 先分清三个时间窗口

- 季度经营进度：季初至看板最新可查日，对照目标和时间进度。各项目投放产出：当月1日至本期已确认截止日。近两周素材：按已确认的14天交付日期窗口，不用发布日期或素材编号里的日期替代。每张图写自己的窗口，不把月累计写成双周新增。
- 复用当期确认套图前核对版本。工单、现金、签约、实缴、费用分别标实际覆盖；腾讯网页不可用时保留已核实费用，缺失不填零。只有当期业务已确认，才写“下周补完整版”。

## “做了多少条”必须另算

从腾讯文档「内容产出流水」全表取数，不从八项目投放套图、反馈表、账号发布篇数反推。先统计窗口内登记条数，再按素材核对交付与状态。待拍、待剪和已确认未完成的记录不算生产；待发布不等于未制作，须核对交付记录。日期与状态冲突单列。状态空白不能独自证明完成：有交付日期但仍无法确认的，若采用登记估算，标“按交付登记暂计”，不称已核实成品或已发布。缺交付日期不默补。

按真实素材 ID 去重，跨平台、跨项目展示只生产一次；同名不同 ID 不合并，未编号按原表行保留。分成**仅投流、仅自然流、两者共用**三个互斥组；官号／IP号按原用途归入自然流或共用，用途不明单列。对外同时交代：

- 去重总量＝仅投流＋仅自然流＋共用（另列用途不明，如有）。
- 用于投流＝仅投流＋共用；用于自然流＝仅自然流＋共用。两者不能直接相加。
- 正文、套图、钉钉和后续 PPT 逐一核对数字对应的是“投放登记”“按交付暂计”“已发布”还是“工单／资源”。GEO 实习生批量生产另外报告；不按日均量乘天数冒充实产，不计入内容组逐条登记总数。

## 图表与图外分析

1. 先看用户打开或导入的上期钉钉模板和本期手改稿。保留四块：业绩分析、近两周投放与素材分析、下周素材计划、两周内核心关注点。每组清晰图片后紧接可编辑分析：哪个版本有效、依据是什么、下周保留或调整什么。不能只贴文字或一张长截图。
2. 语培按留学预备、高中、大学分别写。留学及小语种先放整体平台投产总表（费用、资源、期间金额、单条成本、ROI），再按英澳、北美、欧亚、小语种、学术中心分别列素材名称／ID、日期、用途、花费、工单和判断。共用费用不硬拆；留学签约与小语种实缴注明区别。
3. 用业务名称**历史素材汇总**。同项目、同平台范围内：历史花费＝期间已知费用－新素材已填花费；历史工单＝期间投流工单／资源－新素材已填工单。列出可核实的历史签约或报名金额；新旧无法拆分时列期间总额并标明，不用总额冒充历史签约。费用缺失、反馈跨期或未填时注明估算及遗漏范围；不可比的平台不硬减。GEO服务费不归入历史创意素材花费。
4. 融合素材按**内容适用方向**列示，不要求原登记同时选中两条线。高中或大学讲香港，可在欧亚加列；考研与留学等通用内容在英澳、北美、欧亚各列一次。保留原项目、ID、用途，分开写“本项目投放几条＋融合几条”，自然流融合不变成投流，全组不重复加产量、费用或工单。
5. 自然流、SEM、GEO各自单列。浏览量不等于工单；SEM按账户实填日期列示。GEO按合同分别核算语培和留学：季度金额×报告期内实际服务天数÷约定季度天数，起止日均计入且不跨合同边界；用90天估算时明示。合同金额、有效期和起算日须核实，不能每期从月初重新起算或把全部季度费用一次计入。
6. 下周计划读[新媒体内容组项目进度表·各账号排期表](https://docs.qq.com/sheet/DVHN6SHNaRW94cndC?tab=8506o4)。八个项目各选一个重点主题，沿用原表内容；下周已有排期的写日期，没有排期的注明“原表选题，建议复用”，不要虚构排期。关注点不超过三项，写清怎么检查结果。

交付前核验：图文数字一致、图能打开、当前钉钉草稿保留人工修改。授权填草稿时核对图、图外文字与保存状态；不提交、不群发。等待本阶段确认，不创建定时任务。
