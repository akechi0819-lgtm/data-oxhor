# 核算与交付口径

本规范整合2026年11月15日用户最终确认，用户新指示优先；不保留已被推翻的“仅当前在投”筛选。

## 周期和归属

- 全部线上量取本期正式项目归属，不限投流平台。语培按已确认工单分配日期与业务组、线上规则；留学按资源发生日期、线上平台范围和正式项目字段。工单／资源单位明确标识，不无条件混为同一人头。
- 投流平台目前为小红书、抖音、百度、腾讯广告、GEO；其余线上渠道在非投流组列示。此为已确认渠道分组，不声称每条平台私信都已逐单广告归因。GEO优先使用原渠道“GEO优化”，避免被常规映射归入市场活动或电访而漏算；同一记录只计一次。
- 语培金额：已确认期间新生正向报名现金，标题写期间报名现金。留学：期间签约产出；小语种：期间实缴。不要把期间金额写成同批工单转化。
- 学术中心：资源按留学资源源表 `business_line`（中文“归属条线”）等于“中外合作办学”筛选，按资源ID和正式去重规则核验。不能用国家推导的英澳／北美／欧亚归属替代。素材仍取产品中心的学术力＋就业力。签约按签约发生日期和可验证关联单独核算；没有本期新增资源不代表没有本期签约。
- 归属有缺口时，区分源数据无记录、字段无直接值、映射未确认、接入失败，不笼统写“未接入”。

## 费用及效率

- ROI＝期间产出÷费用；单条成本＝费用÷同口径工单／资源数，分母0或缺失时留空。
- 语培用项目费用；留学费用不能拆北美、英澳等时，第二模块展示留学整体（含小语种）费用、产出与资源。首屏仍只展示本项目。
- 费用没接入标灰并简明说明，不把空白填成0，不标“暂算”。费用只有部分日期有数据时，按用户已确认方式用现有金额计算，同时在正式文字交代覆盖缺口，不冒称全期完整。
- SEM每次核对文件月份、具体工作表、日期行和消费／现金消费的既有金额口径。GEO需有明确对应费用项；“智能体”不自动等于GEO。汇总页公式把明细空白算为0，不代表该日已填写。
- 不分摊未确认的语培整体SEM，不重复累加账户页与项目拆解页。

## 素材

- 新素材按本次确认的登记交付日期窗口（通常近两周）和“内容用途＝投放”纳入。周报窗口与素材窗口可不同，但本次必须明确。无需“在投”状态，不因无花费排除。自然流／官号用途不纳入；原表用途冲突留证据，不能只按标题猜。
- 原登记日期优先于ID内日期。没有可靠日期或日期越界不猜测补入；留作缺口。没有ID但有明确投放用途和窗口内日期时按原表行单列，标“未编号”。
- 同一真实ID跨平台合并花费、工单数；同ID同平台多条记录先查是否重复／不同统计期，不能盲加。同名不同ID独立编号。
- 图中仅列名称／ID、交付日期、花费、已产出工单数；不列待拍摄、待剪辑、待发布等制作状态，也不在配文追加这类解释。
- 用户确认素材原表空白在图中按0展示。证据保留原空值；配文简洁注明“未填反馈按0展示，补齐后调整归集”。真实0与显示0不可在数据层混同。
- 历史素材只一行：本期投流总产出－新素材产出。2026年11月1—13日本轮用户确认同一口径；后续继续采用此规则，但每期核查来源范围、截止日及单位是否发生变化。若有变化，明确缺口后再计算，不把旧确认强套在不同数据上。
- 差额归集不等于逐条历史素材归因；新素材未反馈时，差额可能包含待补录新素材。更新反馈后回拨，不能把差额称为精确追踪结果。
- 历史花费只有在同项目、同周期、同范围完整费用可用时才减。不得以留学整体费减英澳新素材费。不具备条件写“无法拆分”。

## 重点工单

原表反馈优先，其次工单数仓资源描述／跟进字段；从本期线上流转工单中取，不限新素材。重点指咨询方向，不指质量高或签约意愿强；状态不是排除条件。不要把广告名称命中当作客户实际需求。

| 项目 | 重点方向 |
| --- | --- |
| 留学预备 | 低龄英语启蒙 |
| 高中 | 初三客户 |
| 大学 | 封闭营、集训营 |
| 英澳 | 蒙纳士国内班、新南威尔士预科、对应国内预科升学路径 |

工单概况写客户背景、咨询需求、实际跟进，不写筛选规则。没有匹配工单直说暂未发现，不用泛雅思或泛留学意向凑数。
