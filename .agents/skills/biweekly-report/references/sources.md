## 计算与对账

- 工单成本＝对应范围已知花费 ÷ 对应工单数；工单为 0 或缺失时不可计算，显示“—”，不要把缺值补零。
- 参考 ROI＝相同归属和尽可能同一时间范围的现金 ÷ 已知花费。注明参考值与费用覆盖；平台现金可能包含自然流、跨期回收，不能称为单素材的真实投放 ROI、利润率或同期转化。反馈表本身可能没有单素材现金；单素材仅在有可归因现金与相应花费时计算 ROI，否则“—”，不能用平台现金代入。
- 分别记录季度整体、双周交付和素材累计反馈的日期，不混为同期新增。若无法确认反馈的统计截止日，则标注“读取时可见的累计登记，实际截止日待确认”；读取时间、实际投放日期均不自动等于统计截止日。部分数据可查时展示已知范围，标注截止日和缺失，不能将缺失费用、工单或现金默认为 0。
- 差额仅在平台、业务归属、日期、指标定义一致且新素材属于平台整体时计算；还需标注结果可能含历史及未关联素材，工单总数若含自然流，差额也可能含自然流。范围不一致时分别列示，不做看似精确的差额。
- 素材同 ID 多平台按平台区分；依据内容用途字段或已确认的映射归类，无法确认用途的单列未归类。标签、渠道或日期不明时保留未填，不根据标题补标签，不把跨平台花费强行分摊。不能把工单反馈明细和素材反馈汇总简单相加。

周报图片呈现数据，分析写成图片外文字；数字保留可以追溯的来源、范围与关键口径。对腾讯文档、看板记录本期读取时间、选区、截止日和必要的导出或截图证据，避免只保留临时缓存或脚本硬编码。建议在正式报告目录保留源 HTML、高清图片及必要附件，证据放 `Evidence/`，不依赖 `Scratch/` 才能打开。
